Лицензионное соглашение

на использование приложения «Бизнес-справочник РФ» для Битрикс24 · редакция от 30 сентября 2026 г.

1. Стороны и термины

Лицензиар — Поляков Иван Романович, физическое лицо, правообладатель приложения «Бизнес-справочник РФ» (далее — Приложение).

Лицензиат — пользователь или организация, которые установили Приложение на свой портал Битрикс24 через Битрикс24 Маркетплейс.

Приложение — MCP-сервер, который подключается к ИИ-ассистенту Битрикс24 через MCP Hub и даёт ему инструменты: сведения о компаниях и ИП из ЕГРЮЛ/ЕГРИП, проверку реквизитов, данные о банке по БИК, курсы валют и ключевую ставку Банка России, расчёт неустойки и расчёты по производственному календарю.

2. Предмет соглашения

Лицензиар предоставляет Лицензиату простую (неисключительную) безвозмездную лицензию на использование Приложения по его функциональному назначению на всей территории мира на весь срок, пока Приложение установлено на портале Лицензиата.

Установка Приложения означает полное согласие Лицензиата с этим соглашением.

3. Стоимость

Приложение предоставляется бесплатно. Платных функций и подписок в Приложении нет.

4. Источники данных и характер результатов

Приложение получает данные из открытых источников: сервиса ФНС России egrul.nalog.ru, сайта Банка России cbr.ru, сервисов isdayoff.ru (производственный календарь) и bik-info.ru (справочник БИК). Проверка контрольных сумм реквизитов выполняется без обращения к сети.

Результаты носят справочный характер и не являются юридической, налоговой или бухгалтерской консультацией. Лицензиар не отвечает за полноту, точность и своевременность данных внешних источников и за решения, принятые на их основе. Перед значимыми действиями (платёж, заключение договора) сверяйте сведения с официальным источником.

5. Условия использования

  • Приложение предоставляется «как есть». Лицензиар стремится к бесперебойной работе, но не гарантирует её, в том числе при недоступности внешних источников.
  • Чтобы защитить сервис от перегрузки, действует ограничение частоты запросов (по умолчанию 60 запросов в минуту с одного IP-адреса).
  • Запрещено использовать Приложение для действий, нарушающих законодательство РФ, и для намеренной перегрузки сервиса.
  • Исходный код Приложения открыт и распространяется по лицензии MIT: github.com/penmadebykisss/ru-business-mcp.

6. Данные Лицензиата

Приложение не запрашивает доступ к данным портала Битрикс24 (CRM, задачам, пользователям, файлам). Порядок обработки данных запросов описан в Политике конфиденциальности.

Соглашение действует с момента установки Приложения до его удаления с портала. Лицензиат может прекратить использование в любой момент, удалив Приложение.
